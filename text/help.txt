How to use Pathing Plus:

- Use the Drawing and Eraser tools to draw paths on the map.
- Alternatively, click on individual nodes that you want to visit.
- Double-click on node types to select all nodes of that type.
- When paths have been completed, the Legend will show node type counts.
- Use the Legend to pin down a desired path.
- Use the Zoom Out / Rotate button for alternate views of the map.

This mod was also designed with FULL GAMEPAD SUPPORT in mind, specifically:
- In zoomed out modes, you can use the d-pad to move a cursor around the map and select nodes.
- In drawing mode, you can switch between draw and eraser with the left analog stick button.
