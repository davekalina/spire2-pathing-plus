# Every short piece of text the mod puts on screen, in English.
#
# One "key = value" per line. The key is what the code asks for; never change it.
# The value is everything after the first "=", and is free to edit. Lines starting
# with # are comments.
#
# Each language has its own copy of this file in text/<language>/strings.txt, named
# with the game's own language code (zhs, zht, ...). A key missing from a translation
# shows in English instead, so a translation can be partial. Text in {braces} is filled
# in by the mod and must be kept, unchanged, in every language.
#
# The help panel is a separate file beside this one: help.txt.
